How it works

No servers, no queues, no headless browsers. One Worker, one D1 database, and the public HTML pages MyAnimeList already serves to everyone.

01

Fresh? Serve from D1.

Cached data within TTL (6 h for most resources, 2 h for user lists) is returned straight from the edge database — MyAnimeList is never touched.

02

Miss? Fetch once, parse, persist.

A cache miss fetches the public page a single time, runs a pure HTML parser, validates the document, and stores the normalized result. Refresh locks stop thundering herds.

03

Upstream down? Serve stale.

If a refresh fails and a stale copy exists, you still get a 200 — flagged with meta.stale: true instead of an error. Valid data is never replaced by a suspicious document.

Rate limits — two per-IP windows enforced globally across all routes, mirroring Jikan's own policy: 30 req / 10 s burst and 60 req / min sustained. Exceeding either returns 429 with a Retry-After header.

Migrating from Jikan?

Using an AI coding agent (Claude Code, Cursor, Copilot…)? Paste this prompt and let it port your project from api.jikan.moe/v4 to jikan-edge. It carries everything the agent needs to know — envelope, naming, pagination, rate limits and the routes we don't serve.

agent-prompt.txt 
Migrate this project from the Jikan API (https://api.jikan.moe/v4) to jikan-edge
(https://jikan-edge.lucas-hdo.workers.dev/v1). Full docs: https://jikan-edge.lucas-hdo.workers.dev/docs

Key differences to apply:
1. Base URL: replace https://api.jikan.moe/v4 with https://jikan-edge.lucas-hdo.workers.dev/v1.
   Route paths and groups mirror Jikan v4 (anime, manga, characters, people, users, seasons,
   schedules, top, producers, clubs, magazines, watch, reviews, recommendations, random).
2. Response envelope: every success is { "data": ..., "meta": { cached, stale, refreshFailed,
   fetchedAt } }. There is no Jikan-style "pagination" object; pass ?page= (1-based) and read
   list lengths directly. User lists also accept ?limit= (1-300, default 100).
3. Field naming: camelCase instead of snake_case (mal_id -> malId, title_english -> titleEnglish).
   Images are flat URL strings (imageUrl), not Jikan's nested images.jpg/webp objects.
4. Errors: { "error": { code, message, requestId } } with HTTP status. Handle 429 RATE_LIMITED by
   honoring the Retry-After header (limits: 30 req/10s and 60 req/min per IP).
5. meta.stale === true means a served-from-cache fallback after a failed refresh - treat as valid.
6. Not served (adjust or remove features that depend on them): genres/anime, genres/manga,
   clubs?q= (club search), top/reviews, users/:u/history, users/:u/external, users/userbyid/:id,
   per-episode forum. Also: anime/:id/episodes returns only MAL's first page, streaming may be
   empty (geo-dependent), random/* draws from jikan-edge's local cache only.

Steps: find every Jikan call site; swap the base URL; update response parsing to the envelope and
camelCase fields; adapt pagination and rate-limit handling; then verify each migrated endpoint
against the live API before finishing.

Every non-served route above is a documented investigation, not a gap — see the limitations table in the docs.

Not affiliated with MyAnimeList or Jikan. All data comes from publicly accessible MyAnimeList pages, cached aggressively and rate-limited to keep upstream load minimal. If you are MyAnimeList and have concerns, please open an issue.
